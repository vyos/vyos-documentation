```python
              'autosectionlabel',
              'myst_parser',

              'vyos',

```

- [ ] **Step 2: Add sitemap configuration variables**

Add the following after the `autosectionlabel_prefix_document = True` line (around line 58):

```python
# sphinx-sitemap configuration
html_baseurl = 'https://docs.vyos.io/'
sitemap_url_scheme = '{lang}{version}{link}'
sitemap_locales = [None]
```

- [ ] **Step 1: Push and create PR**

```bash
git push -u origin feat/sitemap-generation
gh pr create --title "Add sphinx-sitemap for full per-page sitemap generation" --body "$(cat <<'EOF'
## Summary
- Add `sphinx-sitemap==2.6.0` dependency
- Configure sitemap generation in `conf.py` with RTD-compatible URL scheme
- Replaces RTD's minimal 4-URL auto-sitemap with full per-page sitemaps (~250 URLs per version)
- Future-proofed for i18n via `sitemap_locales` config

## How it works
Each version build produces a `sitemap.xml` with every page. RTD merges these into a `sitemapindex.xml` at `https://docs.vyos.io/sitemap.xml`. The existing `robots.txt` already points to this URL.

## Test plan

- [ ] Verify individual page URLs appear in version sitemaps

🤖 Generated with [Claude Code](https://claude.com/claude-code)
EOF
)"
```
