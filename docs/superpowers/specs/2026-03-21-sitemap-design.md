# Sitemap Generation Improvement — Design Spec

**Date:** 2026-03-21
**Scope:** Replace RTD's minimal 4-URL auto-sitemap with full per-page sitemap via sphinx-sitemap
**Delivery:** 1 PR

---

## Problem

The current sitemap at `https://docs.vyos.io/sitemap.xml` is auto-generated by Read the Docs and contains only 4 URLs (one per active version root). None of the ~250 individual documentation pages are listed, severely limiting search engine discoverability.

## Solution

Add the `sphinx-sitemap` extension to the Sphinx build. Each version build produces a `sitemap.xml` with every page. RTD merges these into a `sitemapindex.xml` at the domain root, replacing the current stub.

---

## Changes

### 1. Add dependency

**File:** `requirements.txt`

Add `sphinx-sitemap` to the existing dependencies list.

### 2. Configure Sphinx

**File:** `docs/conf.py`

Add to `extensions` list:
```python
'sphinx_sitemap',
```

Add configuration variables:
```python
html_baseurl = 'https://docs.vyos.io/'
sitemap_url_scheme = '{lang}{version}{link}'
sitemap_locales = [None]
sitemap_excludes = [
    'search.html',
    'genindex.html',
    '404.html',
]
```

**Configuration rationale:**

- `html_baseurl` — Required by sphinx-sitemap for absolute URLs. RTD overrides this per-version automatically during builds.
- `sitemap_url_scheme = '{lang}{version}{link}'` — Matches RTD's URL structure (`/en/latest/page.html`, `/en/1.4/page.html`). The `{lang}` placeholder is future-proofed for i18n.
- `sitemap_locales = [None]` — Suppresses language variants until translations are configured. English-only for now.
- `sitemap_excludes` — Keeps utility/generated pages out of the sitemap (search, genindex, custom 404).

### 3. No changes needed

- **`docs/_html_extra/robots.txt`** — Already points to `https://docs.vyos.io/sitemap.xml`. No change required.
- **`.readthedocs.yml`** — No sitemap-specific config needed. RTD automatically detects and merges per-build sitemaps.

---

## RTD Integration

When sphinx-sitemap is present in a Sphinx build on RTD:

1. Each version build produces `sitemap.xml` in its build output (e.g., `/en/latest/sitemap.xml`)
2. RTD detects the per-version sitemaps and generates a `sitemapindex.xml` at the domain root
3. The domain-root `sitemap.xml` becomes a sitemap index referencing each version's sitemap
4. The `robots.txt` `Sitemap:` directive already points to the right URL

**Expected result:** `https://docs.vyos.io/sitemap.xml` will contain references to:
- `https://docs.vyos.io/en/latest/sitemap.xml` (~250 URLs)
- `https://docs.vyos.io/en/1.4/sitemap.xml` (~250 URLs)
- `https://docs.vyos.io/en/1.3/sitemap.xml` (~250 URLs)
- `https://docs.vyos.io/en/1.2/sitemap.xml` (~250 URLs)

---

## Future: i18n Readiness

When translations are introduced:

1. Change `sitemap_locales = [None]` to `sitemap_locales = ['en', 'de', ...]` (or whatever languages are added)
2. sphinx-sitemap automatically generates `hreflang` alternate links in each sitemap entry
3. No other configuration changes needed
