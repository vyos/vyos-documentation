::::{cfgcmd} set interfaces {{ var0 }} \<interface\> {{ var2 }} {{ var3 }} {{ var5 }} {{ var6 }} description \<description\>

**Configure a clear, descriptive alias for the interface.** 

This alias appears in the :opcmd:`show interfaces` command and SNMP-based 
monitoring tools.

Example:

```none
set interfaces {{ var0 }} {{ var1 }} {{ var2 }} {{ var4 }} {{ var5 }} {{ var7 }} description 'This is an interface running on VyOS.'
```
